Configuración pendiente: Para que el dashboard lea y guarde datos en Google Sheets, necesitas configurar el Apps Script.
1. Abre el Google Sheet de Tareas 2026 → Extensiones → Apps Script
2. Pega el código del archivo appsscript.js y guarda
3. Haz clic en Implementar → Nueva implementación → Aplicación web → Ejecutar como: Yo → Acceso: Cualquier usuario
4. Copia la URL generada y pégala en la variable APPS_SCRIPT_URL de este archivo
Mientras tanto, el dashboard funciona con datos locales.
